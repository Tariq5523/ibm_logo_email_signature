# IBM Logo GIF Generator

A modern web application for generating animated IBM logo GIFs for email signatures.

## 🎯 Features

- **4 Animation Styles**: Choose from Pulse, Swing, Bounce, or Slide animations
- **Live Preview**: See your animation in real-time before downloading
- **Email-Ready**: Generates 200×200px transparent GIFs optimized for email signatures
- **Compatible**: Works with Gmail, Outlook, and Apple Mail
- **Easy to Use**: Simple interface with one-click download

## 🎨 Available Animations

1. **Pulse** (4s) - Gentle breathing effect with subtle scale changes
2. **Swing** (3s) - Pendulum-like swinging motion
3. **Bounce** (2s) - Playful vertical bouncing
4. **Slide** (3s) - Smooth horizontal sliding motion

## 🚀 Quick Start

Visit the live app: **[IBM Logo GIF Generator](https://YOUR-USERNAME.github.io/ibm-logo-gif/)**

1. Select your preferred animation style
2. Preview the animation
3. Click "Download GIF"
4. Add to your email signature!

## 📧 How to Add to Email Signature

### Gmail
1. Settings → See all settings → General → Signature
2. Click the image icon
3. Upload your downloaded GIF
4. Save changes

### Outlook
1. File → Options → Mail → Signatures
2. Click the image icon
3. Select your downloaded GIF
4. Click OK

### Apple Mail
1. Mail → Preferences → Signatures
2. Drag and drop the GIF into the signature area
3. Close preferences (auto-saves)

## 🛠️ Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Local Setup
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
